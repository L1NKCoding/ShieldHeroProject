# Shield Hero Project 
------------------------------------------------------------------------------------
A 2D side-scrolling platformer built in Unity.

The player must block or dodge incoming enemy projectiles and reach the goal line as quickly as possible. Faster completion time results in a higher score.

------------------------------------------------------------------------------------

## Gameplay Features

- Move Left / Right
- Jump
- Shield Block (raises shield in front of player)
- Projectile Deflection
- Ground & Air Enemies
- Score System (time-based scoring)
- Main Menu & Settings
- Scene Transition System
- Restart / Replay System
